# Issue Tracker Configuration: Local Markdown

This repository uses local Markdown files under `.scratch/` to track feature work, tasks, and issues.

## Storage Location

- `.scratch/<feature>/`

## Conventions

- Feature specifications, tasks, and bug reports are stored as Markdown files inside `.scratch/<feature>/`.
- Skills and agents (such as `to-tickets`, `to-spec`, `qa`, etc.) read from and write issue files inside `.scratch/`.
- Tasks can be organized as individual markdown files representing tickets or feature work items.
